Map Data Viewer

Version 2.5, November 2026

Map Data Viewer plots point data, such as wells, on an interactive map and as a scatter plot. Bubble size and color can each show a column from your data, so one view can carry two variables. It runs entirely in your web browser.

How to use it

  1. Click Download template for an example file, enter data in the Data tab, or prepare your own (see Preparing your own data below). The app opens with the template data already loaded; click Clear to remove it.
  2. Choose a CSV or Excel file under Data. The viewer detects number, date and text columns and guesses which columns hold latitude and longitude.
  3. Optionally pick a text column under Filter and tick the values to show.
  4. Choose what sets color and size. Text columns become categories; number and date columns get a colorbar or low/medium/high bins.
  5. Switch views with the buttons at the top right: Map, Surface, Scatter plots and Data. The map and plots have their own color and size settings; the filter applies to all views.
  6. Click a bubble on the map to see all values for that row. Each well is labeled on the map (by well name by default); turn labels off with Show well labels or pick another label column under Map type.
  7. Open Surface to shade the map with estimated values between wells. Pick the parameter and adjust smoothness, detail and opacity; hover over the map to read estimated values. Use the Show wells switch to hide or show the wells on the map or surface.
  8. Open Data to type data into a table or paste cells copied from Excel. Add rows and columns as needed, then click Plot this data. Edit current data brings the loaded data into the table so you can correct it. The table is not saved when the page closes, so use Download CSV to keep your entries.
  9. The scatter-plot view shows four plots. Under each plot choose X and Y, log axes, whether to connect points, and a trendline. The camera icon on a plot saves it as a PNG.
  10. Click Clear to remove the loaded data.

Preparing your own data

You don’t need the template. Any spreadsheet works if it follows these rules:

  1. One header row, then one row per well. Put column names in the first row and nothing above them (no titles, notes or merged cells). Leave no blank rows between wells.
  2. Two coordinate columns are required: latitude and longitude in decimal degrees (WGS84 or NAD83), for example 40.37 and -81.49. West longitudes and south latitudes are negative. Columns named like “Latitude”/“Lat” and “Longitude”/“Long”/“Lon” are detected automatically; otherwise pick them under Map type. Degrees-minutes-seconds and UTM coordinates are not supported, so convert them first.
  3. Everything else is optional and can have any name: a well name or ID for labels, a status or category column for colors and filtering, and any number or date columns for bubble size, plots and the interpolated surface.
  4. Numbers: plain numbers only. Put units in the column name (“Total Depth, ft”), not in the cells (not “17,513 ft”). Avoid thousands separators.
  5. Dates: month/day/year (4/1/1992) or year-month-day (1992-04-01). Use four-digit years where you can. Day/month/year is not supported and would be misread.
  6. Unknown values: leave the cell blank. Don’t use 0, -999, “N/A” or placeholder dates such as 1/1/1900; they are plotted as real values.
  7. Categories: spell them the same way every time (“P&A” and “P & A” count as two categories).
  8. API numbers: keep the dashes, or format the column as Text in Excel so leading zeros aren’t dropped.
  9. Save as CSV (Excel’s “CSV UTF-8” option is best) or as .xlsx. In Excel files, the first worksheet with data is used, and you can switch sheets in the app.

How columns are detected

Column typeDetected whenUsed for
NumberAt least 90% of filled cells are numbers (commas like 1,234 are fine)Size, color, plot axes
DateAt least 90% of filled cells are dates: month/day/year, or year-month-dayColor, plot axes
TextAnything else, including API numbers with dashesColor categories, filter

Blank cells show as <undefined> in gray. Two-digit years follow Excel’s rule: 00–29 become 2000–2029 and 30–99 become 1930–1999.

Good to know

  • Your data stays on your computer. Files are read in the browser and are not uploaded anywhere. The map does request basemap tiles from the tile providers, which sends them the map area you are viewing.
  • An internet connection is needed for the map tiles and the program libraries.
  • Zero or blank values are drawn at the smallest bubble size and are left out of log-scale plot axes.
  • Numeric color bins are quantiles: each bin holds roughly the same number of points.
  • Interpolated surface: values between wells are estimated by inverse-distance weighting, a weighted average of all wells where nearer wells count more. It reproduces well values exactly, cannot predict highs or lows beyond the measured range, and tends to form “bull’s-eyes” around isolated wells. It ignores geology, faults and trends, and it is not kriging. Treat it as a visual guide, not a resource or reservoir estimate. With the area limit on, it is drawn only inside the outline that encloses the wells.
  • Connect points joins points in order of X, separately for each color group. It is meaningful for ordered data (for example, values against depth or date), not for unrelated wells.
  • Trendlines are least-squares fits, as in Excel: linear, exponential, logarithmic, power, polynomial (order 2–6) and moving average. Each can be fitted to all points or to each color group. Exponential and power fits are made on ln(y), so their R² is measured on ln(y) and is not directly comparable with the others. Logarithmic and power fits skip points with X ≤ 0; exponential and power fits skip points with Y ≤ 0. For date axes, X is measured in years from the earliest date. A polynomial with almost as many terms as points will pass through every point; that is not evidence of a real trend.
